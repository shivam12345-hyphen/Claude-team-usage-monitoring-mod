# Claude team usage

## Install
In Claude Code or the Claude desktop app, run:

```
/plugin install team-usage --marketplace shivam12345-hyphen/Claude-team-usage-monitoring-mod
```

Then restart Claude Code.

## Sign in (once)
```
/team-usage login <username> <password>
```

## Use
- A line appears above the prompt. Click it to see everyone's usage.
- Switch between Today, 7 days and 30 days.
- Change your name: `/team-usage name <your name>`
- Open the full view: `/team-usage`
- Sign out: `/team-usage logout`
