# team-usage

A small chip above the Claude prompt that lists everyone on your team who has installed this mod, ranked by Claude Code usage. Click it to expand a leaderboard for today, the last 7 days or the last 30 days: name, a bar and new tokens, with a dot for who is online now and your own row marked. Installing the mod adds you to the list straight away.

It needs no tokens or setup. It adds up your own usage from the transcripts Claude Code keeps on your computer and shares only your name and token totals, never prompts or code. Set the name teammates see with `/team-usage name <your name>`; open the full pane with `/team-usage`.
